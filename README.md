# Core Java Practice

This folder has my java practice programs for the Cognizant Digital Nurture 5.0
program.

## how to run

open the folder in cmd and do:

```
javac HelloJava.java
java HelloJava
```

## Contents

- HelloJava.java - my first program, prints hello
- DataTypesAndVariables.java - int, double, char etc and type casting
- OperatorsDemo.java - plus minus and other operators
- ControlFlow.java - if else and switch case
- LoopsDemo.java - for, while, do while loops + star pattern
- MethodsDemo.java - methods and recursion (factorial)
- ArraysDemo.java - 1d and 2d arrays
- StringsDemo.java - string methods and reverse a string
- OOPDemo.java - classes, inheritance, polymorphism etc
- ExceptionHandling.java - try catch and my own exception
- CollectionsDemo.java - list, set, map, queue
- FunctionalProgramming.java - lambda and streams
- FileHandling.java - writing and reading a file
- MultithreadingDemo.java - threads
- ConcurrencyUtils.java - thread pool
- ReflectionDemo.java - reflection
- Java17and21Features.java - records, sealed, text blocks
- JdbcDemo.java - connecting java to database
- NetworkingDemo.java - http request

jdk 17.
